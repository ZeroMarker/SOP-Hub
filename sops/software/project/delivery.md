## 1. 目的

规范软件项目从立项、计划、执行、监控、验收到结项的交付过程，确保范围、进度、成本、质量和风险受控。

## 2. 适用范围

适用于公司内部软件项目、客户交付项目、平台建设项目、系统升级项目和跨团队协作项目。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 项目章程 | 明确项目目标、范围、资源、里程碑和授权的启动文件 |
| 里程碑 | 项目关键阶段或重要交付节点 |
| 风险登记册 | 记录项目风险、影响、概率、应对措施和责任人的清单 |
| 干系人 | 受项目影响或可影响项目的人或组织 |
| 交付物 | 项目过程中形成并需要验收的成果 |
| 结项 | 项目完成后进行验收、归档和总结的活动 |

## 4. 职责分工

### 4.1 项目经理
- 组织项目启动、计划制定和过程跟踪
- 管理范围、进度、风险和沟通
- 推动问题解决和资源协调
- 组织项目验收和结项

### 4.2 项目发起人
- 明确项目目标和业务价值
- 提供资源支持和关键决策
- 审批重大范围、预算和排期变更

### 4.3 研发负责人
- 负责技术方案、开发计划和交付质量
- 识别技术风险和依赖
- 协调研发资源

### 4.4 测试负责人
- 制定测试计划和质量门禁
- 输出测试报告和质量风险评估
- 支持验收测试

### 4.5 运维负责人
- 制定部署、监控和回滚方案
- 确认上线环境和运维交接
- 支持上线后稳定性保障

## 5. 操作流程

### 5.1 项目启动流程

```
立项申请 → 可行性评估 → 项目章程编制 → 启动会
→ 项目计划基线
```

**详细步骤：**

1. **立项申请**：明确项目背景、目标、范围、预期收益和资源需求
2. **可行性评估**：评估业务价值、技术可行性、成本和风险
3. **项目章程**：明确项目组织、职责、里程碑和验收标准
4. **启动会**：同步目标、范围、计划、沟通机制和风险

### 5.2 项目计划流程

```
范围拆解 → WBS 编制 → 排期估算 → 资源确认
→ 风险识别 → 计划发布
```

**计划内容：**

- 项目范围和不做范围
- 工作分解结构和任务负责人
- 里程碑和关键路径
- 人力、环境、预算和外部依赖
- 沟通机制、会议节奏和汇报模板
- 风险清单和应对策略

### 5.3 项目执行与跟踪流程

```
任务执行 → 进度跟踪 → 问题记录 → 风险处理
→ 变更控制 → 周报同步
```

**管理要求：**

1. 每周更新项目进度、风险、问题和下周计划
2. 关键里程碑延期需提前预警
3. 跨团队阻塞问题需明确责任人和解决时间
4. 重大风险需升级至项目发起人或项目委员会

### 5.4 变更管理流程

```
变更申请 → 影响评估 → 审批决策 → 计划调整
→ 相关方同步 → 变更归档
```

**影响评估维度：**

- 范围影响
- 进度影响
- 成本和资源影响
- 技术风险
- 质量和上线风险
- 合同或客户承诺影响

### 5.5 验收与上线流程

```
交付物检查 → 测试报告确认 → 业务验收 → 上线评审
→ 发布上线 → 稳定性观察 → 验收签署
```

**验收要求：**

- 需求范围全部关闭或明确延期
- 致命和严重缺陷已清零
- 运维文档、用户手册和培训材料已交付
- 上线方案、回滚方案和监控方案已确认

### 5.6 项目结项流程

```
结项申请 → 资料归档 → 复盘总结 → 成本核算
→ 经验沉淀 → 项目关闭
```

**归档内容：**

- 项目章程、计划、周报和会议纪要
- PRD、设计方案、测试报告和发布记录
- 验收单、培训材料和运维交接文档
- 风险问题清单和复盘报告

## 6. 特殊情况处理

### 6.1 重大延期
- 分析延期原因和影响范围
- 提供压缩范围、增加资源或调整排期方案
- 经项目发起人审批后更新计划基线

### 6.2 资源冲突
- 项目经理先进行团队内协调
- 无法解决时升级至部门负责人
- 记录资源调整对项目目标的影响

### 6.3 客户验收争议
- 对照合同、需求文档和验收标准逐项确认
- 争议项形成问题清单和处理计划
- 必要时组织专项评审会议

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 项目计划完整率 | 100% |
| 周报提交及时率 | ≥ 95% |
| 重大风险提前预警率 | 100% |
| 里程碑达成率 | ≥ 90% |
| 验收资料完整率 | 100% |
| 项目复盘完成率 | 100% |

## 8. 信息安全管理

- 客户项目资料按保密等级管理
- 项目成员权限随项目阶段及时开通和回收
- 涉及生产数据的交付物必须脱敏
- 外部共享资料需经项目负责人确认

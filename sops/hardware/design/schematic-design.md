## 1. 目的

规范原理图设计、器件选型、仿真与评审流程，确保原理正确、器件可采、接口可测，一次投板成功率达标。

## 2. 适用范围

适用于新品原理图设计与重大改版；小改款以差异页形式输出。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 网表 | 原理图生成的电气连接数据，PCB设计的输入 |
| 降额设计 | 器件实际应力低于额定值使用（如电容电压降额70%） |
| 信号完整性/电源完整性 | SI/PI，高速信号与电源分配质量仿真验证 |
| 优选库 | 经认证的器件库（封装/规格/供应商三齐），非优选器件需特批 |
| 评审三类结论 | 通过/有条件通过/驳回重做 |

## 4. 职责分工

### 4.1 硬件工程师（设计）
- 按HRS完成架构细化、器件选型、原理图绘制、关键仿真
- 输出BOM初版与测试点规划

### 4.2 资深工程师/专家（评审）
- 主持原理图评审，重点审查电源架构、复位时钟、保护电路

### 4.3 器件管理员
- 维护优选库，审核新增器件（货期/价格/EOL/替代）
- BOM合规性检查（停产料/独家料拦截）

### 4.4 软件/结构（会签）
- 软件确认启动时序/接口电平/功耗模式可实现；结构确认连接器位置与高度约束

## 5. 操作流程

### 5.1 器件选型与预研

```
HRS冻结 → 关键器件对比 → 样片申请 → 预研验证
```

1. **对比表**：主控/电源/无线/传感器四类关键器件必须输出对比表（性能/功耗/价格/货期/技术支持五维）
2. **优选库优先**：非优选器件需附理由+替代预案，经器件管理员会签
3. **预研验证**：高风险电路（新电源拓扑/射频匹配/高速接口）先做DEMO板或仿真，结论写入设计说明；未验证不得进正式原理图

### 5.2 原理图绘制

```
总体框图 → 分模块绘制 → 编号标注 → ERC检查 → 自查
```

1. **绘制规范**：
   - 图纸分级：框图→电源树→各功能模块，电源树单列一页（含各路电压/电流/上下电时序）
   - 位号规则：R/C/L/D/Q/U/J按模块编号（如R301-R399归电源模块），禁止跳号重号
   - 必标项：关键信号走线要求（差分/等长/阻抗）、测试点（电源/时钟/复位/关键总线全覆盖）、NC脚处理、配置电阻默认值
2. **设计红线**：
   - 电源降额：电容耐压≥1.5倍工作电压，电感/磁珠电流≥1.3倍峰值电流
   - 保护：对外接口必加ESD（IEC 61000-4-2），电源入口必加过压/反接保护
   - 时钟复位：晶振负载电容按手册计算，复位电路禁止悬空
3. **ERC与自查**：零ERC错误方可提评审；自查表签字（电源/接地/去耦/NC脚/位号五项）

### 5.3 仿真与评审

```
关键仿真 → 预审 → 正式评审 → 问题关闭 → 原理图冻结
```

1. **必做仿真**（按需勾选）：高速信号SI（DDR/USB/以太网）、PDN阻抗、电源环路稳定性、热仿真（大功耗板）
2. **评审会**：设计讲解+逐页过图，评审记录精确到页码+位号；问题分级：致命（投板前必改）/严重（EVT前必改）/建议（DVT优化）
3. **冻结**：致命+严重问题关闭、网表生成并与BOM一致性校验通过后，原理图V1.0冻结转PCB

## 6. 特殊情况处理

### 6.1 器件缺货需替换
- 同封装同规格替换走快速会签（设计+器件管理员）；改封装或改参数按ECR重评，必要时重开局部评审

### 6.2 评审发现架构缺陷
- 涉及主控/电源拓扑变更的，退回立项阶段重做架构初案，不得“边投板边改”

### 6.3 高速/射频疑难
- 升级专家会诊或求助原厂FAE，结论书面归档；FAE口头建议必须复测验证后才采纳

## 8. 信息安全管理

- 原理图、器件价格、FAE内部资料为机密，评审范围外不扩散
- EDA工程文件纳入版本库（Git/SVN），禁止本地唯一副本
- 对外发板厂仅提供生产文件（Gerber），原理图源文件不外发

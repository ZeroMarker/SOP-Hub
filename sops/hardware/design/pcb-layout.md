## 1. 目的

规范PCB叠层、布局、布线、DFM与Gerber输出流程，确保信号完整、电源稳定、可制造、可测试，贴片一次直通率达标。

## 2. 适用范围

适用于2层以上（含）PCB设计；高频/高速/大功率板执行加严条款。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 叠层 | PCB各铜层与介质排列，直接决定阻抗与EMC |
| DFM/DFA | 可制造性/可装配性设计，板厂与SMT视角的规则检查 |
| 等长/差分 | 高速信号长度匹配与差分对布线要求 |
| 拼板 | 多块小板拼成大板生产，含工艺边与Mark点 |
| Gerber+钻孔+钢网 | 发板三件套：线路/阻焊/丝印+钻孔文件+钢网文件 |

## 4. 职责分工

### 4.1 PCB工程师
- 叠层规划、布局布线、DRC/DFM检查、Gerber输出与归档

### 4.2 硬件工程师
- 提供布局约束（敏感电路/大电流路径/屏蔽要求），确认布局评审

### 4.3 结构工程师
- 确认板框尺寸、安装孔、连接器开窗、高度干涉

### 4.4 SMT工艺
- 确认拼板方式、Mark点、炉温适配性、特殊封装工艺能力

## 5. 操作流程

### 5.1 叠层与布局

```
网表导入 → 叠层规划 → 结构对接 → 布局 → 布局评审
```

1. **叠层规划**：4层常规`SIG-GND-PWR-SIG`；高速板相邻信号层正交，电源地平面完整不挖空；阻抗线提前算好线宽/间距并记录
2. **布局优先级**：接口连接器定位→主控/内存→电源模块→高速信号→一般电路；大电流路径最短，敏感模拟远离开关电源
3. **布局评审**：硬件+结构+SMT三方过图，输出评审记录；布局冻结后才允许布线（布局布线不同步进行）

### 5.2 布线与检查

```
关键信号先行 → 常规布线 → 铺铜/泪滴 → DRC → SI/PI复核 → DFM检查
```

1. **布线红线**：
   - 电源：大电流线宽按1A/mm（1oz）估算，覆铜完整回流，过孔载流复核
   - 高速：差分对内等长≤5mil，包地打孔间距≤λ/20；时钟线包地，两侧禁布敏感线
   - 模拟/射频：单独地岛+单点接地，天线净空区禁铜禁线，匹配电路靠近天线
   - 通用：晶振下方禁线，复位/中断线远离干扰源，测试点引出不被器件遮挡
2. **检查三件套**：DRC零错误+SI/PI复核（高速板）+板厂DFM（线宽间距/孔环/阻焊桥）全部通过
3. **丝印**：位号清晰不被焊盘压盖，极性/一脚标记明确，版本号+日期打板上

### 5.3 输出与发板

```
拼板确认 → Gerber输出 → 首件核对 → 发板归档
```

1. **输出清单**：Gerber（RS-274X）、钻孔（Excellon）、钢网、装配图PDF、坐标文件、阻抗说明、拼板图、工艺要求说明
2. **首件核对**：用CAM350/Gerber Viewer逐层核对（线路/阻焊/丝印/钻孔），双人交叉检查签字
3. **发板归档**：工程源文件+生产文件+评审记录打包归档PLM；发板厂仅收生产文件

## 6. 特殊情况处理

### 6.1 交期紧急跳过评审
- 仅允许2层简单板跳过正式评审，改为邮件会签；4层及以上与高速板永不跳过

### 6.2 板厂反馈超工艺能力
- 优先降工艺等级（加线宽/加大孔环）；确需HDI/盲埋孔则换厂并重做DFM

### 6.3 改版
- 改版标注版本号递增（V1.0→V1.1小改/V2.0大改），改动区域云线标注，旧版Gerber作废归档

- PCB源文件纳入版本库，Gerber输出记录可追溯（谁/何时/哪版）

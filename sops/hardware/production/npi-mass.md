## 1. 目的

规范EVT→DVT→PVT→MP（量产）四阶段导入流程，确保试产问题清零、产线 capability 达标后才放量，避免量产批量事故。

## 2. 适用范围

适用于自有工厂与代工厂（OEM/ODM）的全部硬件产品量产导入。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| NPI | 新产品导入，试产阶段的工程主导者 |
| 直通率（FPY） | 一次通过 dura？一次通过所有测试的比例，量产核心指标 |
| 工装夹具 | 测试架、烧录架、组装夹具等生产辅助工具 |
| SOP（作业指导书） | 产线工人操作步骤卡，与设计SOP同名异物，此处指产线作业文件 |
| 放量标准 | 进入量产的数量/良率/问题关闭门槛 |

## 4. 职责分工

### 4.1 NPI工程师（主责）
- 主导试产计划、产线交底、问题跟踪关闭、放量评审组织

### 4.2 研发（硬件/软件/结构）
- 提供生产文件包（Gerber/BOM/固件/3D图），现场支持问题定位，签发改版

### 4.3 品质部（SQE/IQC/IPQC/OQC）
- 来料/制程/出货三段检验，试产报告签发

### 4.4 代工厂
- 按生产文件组织试产，输出制程数据（直通率/不良TOP），执行整改

## 5. 操作流程

### 5.1 试产三阶段

```
EVT（工程样）→ DVT（设计定型）→ PVT（生产验证）→ MP（量产）
```

| 阶段 | 数量建议 | 目标 | 放行条件 |
|------|----------|------|----------|
| EVT | 5-20台 | 功能验证，允许飞线 | 致命Bug清零，原理可定 |
| DVT | 50-200台 | 设计定型+可靠性验证 | 严重Bug清零，BOM/文件冻结 |
| PVT | 200-1000台 | 产线验证（工装/节拍/直通率） | FPY达标，SOP/工装齐套 |
| MP | 批量 | 稳定量产 | PVT问题100%关闭 |

### 5.2 试产执行

```
生产文件包 → 产前交底 → 首件确认 → 批量试产 → 制程检验 → 试产评审
```

1. **生产文件包**：Gerber+钢网+BOM（含替代料清单）+装配图+测试固件（冻结版本）+检验标准+包装要求，缺件不排产
2. **产前交底**：NPI+研发向产线交底（难点工位演示、易错器件警示），输出交底记录
3. **制程数据**：每阶段统计FPY、不良TOP3、维修记录；FPY红线：EVT不考核、DVT≥90%、PVT≥95%（消费类参考值，工业品加严）
4. **试产评审**：问题清单逐条过（设计/来料/制程/工装四类），结论：放行下阶段/整改后复产/暂停

### 5.3 量产放行与切换

- **放量标准**：PVT问题100%关闭、FPY连续2批达标、工装夹具验收通过、售后备件与维修手册齐备
- **工程切换**：量产中任何变更（器件/工艺/工厂）走ECN，按变更等级决定重验证范围（A类重做PVT，B类做差异验证，C类备案）

## 6. 特殊情况处理

### 6.1 试产FPY不达标
- 停线分析：区分设计/来料/制程责任；设计问题研发48小时内给对策，来料问题SQE限期索赔补货，制程问题工厂即时整改

### 6.2 量产突发批量不良
- 启动 containment：冻结库存+在途+已发货待确认批次，8D限时（24h围堵、7天根因、30天关闭），同类产品横向排查

### 6.3 代工厂配合度不足
- 升级商务+技术双通道施压；连续两阶段不达标启动第二供应商导入，原厂份额递减

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 试产计划准时启动率 | ≥ 95% |
| 生产文件包一次齐套率 | ≥ 95% |
| PVT直通率 | ≥ 95%（消费类） |
| 试产问题按期关闭率 | 100%（放量前） |
| 量产三个月内批量事故 | 0起 |

## 8. 信息安全管理

- 生产文件包按订单授权发放，代工厂到期/终止合作书面确认删除
- 测试固件分级：量产烧录版与研发调试版分离，调试接口量产版本关闭或设密

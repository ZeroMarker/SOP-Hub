## 1. 目的

规范样机上电调试、功能测试、性能测试、可靠性测试与问题闭环流程，确保设计缺陷在量产前收敛，测试结论可复现、可追溯。

## 2. 适用范围

适用于EVT（功能验证）、DVT（设计定型验证）、PVT（生产验证）三阶段硬件测试。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 上电时序 | 各路上电先后顺序与间隔，不合规导致锁死或闩锁 |
| 裕量测试 | 高低温/高低压拉偏测试，验证设计余量 |
| Bug分级 | 致命（冒烟/烧毁/安全）/严重（功能失效）/一般（性能偏差）/建议（优化） |
| 回归测试 | 修复后对原问题+关联功能的复测 |
| 测试冻结 | 测试用例与测试环境版本锁定，测试中途不换niej换板换软件需记录 |

## 4. 职责分工

### 4.1 硬件测试工程师
- 编写测试计划与用例，搭建测试环境，执行测试并输出报告

### 4.2 硬件设计工程师
- 样机上电调试，定位分析Bug，输出改版方案，复测确认

### 4.3 品质部（QE）
- 审核测试计划充分性， witness 关键测试（安规/可靠性），签发阶段放行结论

### 4.4 软件/结构（配合）
- 提供联调固件版本（冻结编号），确认结构/散热配合测试条件

## 5. 操作流程

### 5.1 上电调试（Bring-up）

```
目检 → 电源空载测 → 上电 → 时钟复位测 → 最小系统启动 → 功能初测
```

1. **上电前**：电源对地阻抗必测（万用表），电源入口保护器件确认无虚焊；限流电源首次上电（限流值=预估电流1.5倍）
2. **最小系统**：先调电源（各路电压±3%内、纹波达标）→时钟（频率/幅度）→复位时序→JTAG/SWD连通→Boot启动
3. **调试记录**：每步实测数据记入《调试记录表》，异常波形截图存档；调通的样机编号锁定为测试基准机

### 5.2 功能与性能测试

```
测试计划 → 用例评审 → 环境搭建 → 执行 → Bug提交 → 修复 → 回归 → 报告
```

1. **测试计划**：按HRS逐条映射用例，覆盖接口全遍历、上下电100次、长时间烤机（≥72h）、功耗（工作/休眠/关机三态）
2. **性能测试**：关键指标（射频灵敏度/发射功率、高速眼图、ADC精度、电源效率/负载调整率）实测+裕量拉偏（电压±5%、温度上下限）
3. **Bug管理**：必含复现步骤+实测数据+波形/照片+样机编号+软件版本；致命/严重Bug必须修复+回归通过才放行下阶段

### 5.3 可靠性测试（DVT重点）

- 必测项：高低温工作/存储、温循、振动、跌落、ESD（接触±8kV/空气±15kV）、浪涌（电源口）、盐雾（户外品）
- 判据：功能正常+外观无开裂+关键参数漂移≤标称10%
- 失效分析：8D报告（现象→复现→根因→对策→验证），根因定位到器件/设计/工艺三类

## 6. 特殊情况处理

### 6.1 偶发Bug难复现
- 加码测试（样本量×3、温箱拉偏、长时间烤机），同步上逻辑分析仪/示波器长时间捕获；仍无法复现则标记遗留风险，DVT评审会裁决是否放行

### 6.2 测试阻塞（样机不足/环境故障）
- 样机不足：先测单板级（电源板/主控板独立测试），整机测试排队；环境故障：转等效条件测试并记录偏差，恢复后补测关键项

### 6.3 致命Bug（冒烟/烧毁）
- 立即断电封存现场（样机+电源+线缆原样保留），24小时内出初步分析，整改+复测通过前暂停同批次所有测试

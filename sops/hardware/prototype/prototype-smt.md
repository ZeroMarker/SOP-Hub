## 1. 目的

规范PCB打样、物料齐套、SMT贴片、目检与样机交付流程，确保样机按时可用、焊接可靠、问题可追溯。

## 2. 适用范围

适用于EVT/DVT/PVT各阶段样机打样；研发手工样执行简化条款。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 齐套 | BOM全部物料到齐；缺料分A类（关键）/B类（可后补） |
| 首件 | SMT首块贴完并全检确认的板子，后续生产的基准 |
| 炉温曲线 | 回流焊温度-时间曲线，不同封装需匹配 |
| 目检+AOI/X-ray | 目视+自动光学检测+BGA封装X射线检测 |
| 改线/飞线 | 样机阶段临时修正，需记录并在下版消除 |

## 4. 职责分工

### 4.1 硬件工程师
- 输出打样资料包，跟线（首件确认），样机功能初测，记录改线

### 4.2 采购部
- 物料下单催料，输出齐套表，预警长交期料

### 4.3 IQC
- 来料检验（丝印/封装/引脚氧化/数量），贴前BOM符合性复核

### 4.4 SMT工厂
- 钢网核对、首件制作、炉温调试、批量贴片、目检/AOI报告

## 5. 操作流程

### 5.1 打样下单与齐套

```
打样资料包 → PCB下单 → 物料下单 → 齐套核算 → 贴片排期
```

1. **打样资料包**：Gerber+钻孔+钢网+装配图+坐标文件+BOM（含替代料标注）+特殊工艺说明（阻抗/沉金/塞孔）
2. **PCB下单**：常规样板5-7天加急可选；阻抗板要求板厂附阻抗测试条报告
3. **齐套核算**：A类料（主控/电源/连接器）100%到齐才排贴片；B类料（调试电阻电容/指示灯）缺料可先贴，清单挂账后补
4. **BOM复核**：IQC按BOM核对位号/封装/数量三项，错料拦截在贴片前

### 5.2 SMT贴片与检验

```
钢网核对 → 首件 → 炉温确认 → 批量贴片 → 目检/AOI → X-ray（BGA）→ 样机交付
```

1. **首件确认**：首块贴完硬件工程师现场确认（极性/方向/错位/连锡），签字后批量生产
2. **检验标准**：目检全覆盖（虚焊/立碑/连锡/偏移），BGA/QFN抽X-ray（空洞率≤25%），AOI报告随货
3. **交付物**：样机+检验报告+改线记录表+剩余物料退库单；样机编号管理（EVT-01/02…），每台去向登记

## 6. 特殊情况处理

### 6.1 缺料
- A类缺料：换替代料（走快速会签）或拆分两批贴（先贴有料部分，缺料后补，补焊记录存档）
- 停产料：触发器件替换流程，不得用拆机件/散新货顶替样机关键器件

### 6.2 批量焊接不良
- 同一缺陷≥3块即停线：先查钢网/炉温/来料引脚氧化三要素，整改后重做首件

### 6.3 样机改线
- 每根飞线编号记录（原因/位置/下版对策）；单板飞线超10根必须在下版前开评审，评估改版而非继续飞线验证

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 打样资料一次齐套率 | ≥ 95% |
| SMT首件一次通过率 | ≥ 90% |
| 样机准时交付率 | ≥ 95% |
| 焊接直通率（AOI） | ≥ 98% |
| 样机编号与去向登记完整率 | 100% |

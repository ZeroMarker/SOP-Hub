## 1. 目的

规范国内外认证（强制+目标市场准入）的策划、摸底、送检、整改与证书维护流程，确保产品上市前拿证，避免下架与罚款风险。

## 2. 适用范围

适用于整机与关键模组（无线/电源）的认证管理。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 强制认证 | 上市前置条件，如中国3C、欧盟CE（LVD/EMC/RED/RoHS）、美国FCC |
| 摸底测试 | 正式送检前在内部或实验室的预测试，提前暴露问题 |
| 符合性声明 | DoC/SDoC，制造商自我声明合规的技术文件包 |
| 证书维护 | 证书有效期管理、标准换版跟进、工厂检查应对 |
| 系列申请 | 同一平台多型号共用测试数据的派生认证 |

## 4. 职责分工

### 4.1 认证工程师（主责）
- 制定认证计划（国家/标准/时间/费用），对接实验室，跟踪整改闭环，维护证书台账

### 4.2 硬件工程师
- 按认证要求做防护与EMC设计（滤波/屏蔽/接地），执行摸底整改

### 4.3 品质部
- 保有技术文件包（BOM/原理图/说明书/测试报告），应对工厂检查

### 4.4 市场/销售
- 输入目标市场清单与上市时间，确认铭牌/说明书多语言要求

## 5. 操作流程

### 5.1 认证策划（立项阶段同步启动）

```
目标市场输入 → 认证清单 → 计划排期 → 设计输入
```

1. **认证清单**：按销售区域列出强制项（例：国内3C+SRRC，无线产品加型号核准；出口欧美CE+FCC/UL；电池UN38.3+IEC 62133）
2. **设计输入**：认证要求反向写入HRS（EMC等级、安规距离、标签铭牌、说明书警示语），DVT前完成防护设计
3. **排期原则**：摸底在DVT中期，正式送检在DVT后期，证书到手作为PVT放行条件之一

### 5.2 摸底与送检

```
摸底测试 → 整改 → 正式送检 → 发证
```

1. **摸底**：EMC（传导/辐射）、安规（耐压/接地/温升）、射频（功率/杂散/灵敏度）三项必摸底；摸底报告列明超标频点+裕量
2. **送检资料包**：申请表+营业执照+商标+BOM+原理图+PCB版图+说明书+铭牌图+关键件证书（电源/电池/无线模组），资料与送检样机一致性声明签字
3. **整改**：超标项硬件48小时内给对策（滤波参数/磁环/屏蔽/铺铜），复测通过才重送检；同一项目正式送检不通过超2次升级评审（设计/器件/实验室三方会诊）

### 5.3 证书与维护

- **台账**：证书编号/有效期/持证工厂/覆盖型号四要素登记，到期前6个月预警续证
- **标准换版**：收到换版通知3个月内评估差异测试，证书到期前完成转版
- **工厂检查**（3C/CQC）：eth？保持一致性（产线产品与送检样机关键件一致），关键件变更先报备再切换

## 6. 特殊情况处理

### 6.1 上市紧急无证先行
- 原则上禁止；确需国内电商预售的，仅允许“ overseas 仓先行+国内不发货”，法务书面确认风险，责任人签字

### 6.2 测试标准争议（实验室间结果不一致）
- 以发证实验室为准；摸底实验室偏差超3dB即更换摸底渠道并记录

### 6.3 证书暂停/撤销
- 立即停售涉证型号，封存库存，8D追溯（设计变更未报备/关键件偷换/工厂检查不通过），恢复证书前不得复售

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 认证计划覆盖率（目标市场） | 100% |
| 正式送检一次通过率 | ≥ 80% |
| 证书到期前续证完成率 | 100% |
| 关键件变更报备率 | 100% |
| 因认证问题导致的上市延期 | 0起（DVT即启动策划的项目） |

## 8. 信息安全管理

- 技术文件包（原理图/BOM/版图）仅认证工程师与实验室接口人可见，实验室签NDA
- 证书扫描件对外（客户/渠道）提供，测试报告原始数据不外发

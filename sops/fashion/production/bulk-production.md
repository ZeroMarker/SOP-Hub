## 1. 目的

规范从订货下单到大货出运的全过程跟单，确保交期、工艺、数量三达标，减少跳单、延期与产中改版事故。

## 2. 适用范围

适用于自有工厂与外发OEM/ODM工厂的大货生产。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 开裁 | 大货第一刀裁剪，原则上PP样确认后方可开裁 |
| 产前会 | 开裁前公司与工厂的工艺交底会 |
| 在线QC | 生产过程中的巡检（裁床/车位/后道） |
| 尾期 | 大货收尾阶段，核对数量与包装 |
| 出运 | 成衣离厂发往仓库/门店 |

## 4. 职责分工

### 4.1 跟单员（主责）
- 建款跟单台账，全程跟踪面辅料齐套、产前会、在线进度、QC、出运
- 异常第一时间预警并推动解决

### 4.2 工厂（自有/外发）
- 按封样与工艺单组织生产，异常主动上报，不得擅自变更工艺与辅料

### 4.3 QC
- 执行产前/产中/尾期三检，出具检验报告与放行结论

### 4.4 商品企划
- 下达订货数量（分色分码），确认出运波段优先级

## 5. 操作流程

### 5.1 下单与产前准备

```
订货数量锁定 → 生产下单 → 面辅料齐套核算 → 产前会 → PP样确认 → 开裁放行
```

1. **生产下单**：订单注明款号、颜色、码数配比、分包要求、交期、工艺单版本号、封样编号
2. **齐套核算**：面辅料到厂≥95%且头缸已放行方可排产前会；缺关键辅料（主唛/拉链）不得开裁
3. **产前会**（开裁前必开）：
   - 到场：跟单+QC+工厂厂长/组长+制版（复杂款到场）
   - 交底：封样传阅上身、工艺难点演示（包条/开衩/对条）、疵点限度样确认
   - 输出《产前会会议纪要》，三方签字
4. **开裁放行**：PP样确认书+产前会纪要双齐才放行开裁；唛架由工厂排、公司核（利用率/对条/方向复核）

### 5.2 产中跟踪

```
裁剪 → 缝制 → 后整理（水洗/熨烫）→ 包装
```

1. **裁剪跟踪**：核对铺布层数、布卷色差分包、裁片抽查（首捆必检）；裁片编号管理，防窜码
2. **缝制跟踪**：首件确认（第一件成衣对封样全检）；在线巡检每款≥2次，记录返修率；返修率>10%停线整改
3. **后整理**：水洗产品对缸确认（每缸色样留存）；羽绒充绒量抽检；针织量尺寸（平铺+上身双确认）
4. **进度报表**：跟单员每日更新台账（日产量/累计/差异），延期超3天预警、超7天升级

### 5.3 尾期与出运

```
尾期检验 → 数量复核 → 装箱单 → 出运 → 资料归档
```

- 尾期按AQL标准全检/抽检（见质检SOP），合格放行出运
- 装箱按波段/店铺分单，箱唛注明款号/颜色/码数/数量
- 出运后3天内归档：订单、唛架、检验报告、水洗缸单、对账单

## 6. 特殊情况处理

### 6.1 工厂延期
- 3天内：工厂内部加班/调线消化
- 超7天：启动分单（拆色/拆码转备选厂）或空运，费用按合同责任划分

### 6.2 产中发现封样/工艺错误
- 立即停线封存已制品，走ECR评估：能返修返修，不能返修经批准降级/报废，禁止隐瞒流入下道工序

### 6.3 工厂擅自换辅料/改工艺
- 按红线事故处理：该批暂停出运、全检、供应商记大过一次，纳入年度淘汰评分

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 产前会执行率 | 100% |
| 无PP样开裁事故 | 0起 |
| 大货准时出运率 | ≥ 95% |
| 首件确认执行率 | 100% |
| 跟单台账日更新率 | 100% |

## 8. 信息安全管理

- 订单数量、加工费单价仅跟单与财务可见，工厂间不横向透露
- 版型电子版发厂后登记，合作终止即收回并确认删除

## 1. 目的

规范服装全链路软件工具的选型、部署、数据标准与运维，确保款式图、纸样、工艺单、物料、订单数据在各系统间一次录入、全程流转，减少重复建档、版本错乱与License浪费。

## 2. 适用范围

适用于企划、设计、制版、样衣、采购、生产、质检、仓储八个环节全部业务软件。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| PLM | 产品生命周期管理，款式/物料/工艺单/样衣评审唯一数据源 |
| CAD | 制版CAD，纸样制作/放码/排料（唛架），如Gerber/Lectra/ET/博克 |
| 3D样衣 | CLO 3D / Style3D / Browzwear三维试衣，减少实物样轮次 |
| ERP | 企业资源计划，下单/采购/库存/结算，如百胜/丽晶/SAP |
| MES | 制造执行系统，工厂车位进度/工时/返修率采集 |
| QMS/WMS | 质量管理/仓储管理系统，检验报告与入库复检线上化 |

## 4. 工具矩阵（环节×软件×用途）

| 环节 | 必用软件 | 用途 | 输出物归属系统 |
|------|----------|------|----------------|
| 趋势企划 | 趋势平台（WGSN/POP）+ ERP销售报表 + 在线文档 | 趋势报告、OTB分解、波段排期 | 企划书归档PLM/网盘，OTB进ERP |
| 款式设计 | Illustrator/Photoshop（款式图）+ 3D样衣（廓形预演） | 设计稿、花型、配色、工艺单初版 | 设计稿+工艺单进PLM |
| 面辅料 | PLM物料库 + ERP采购模块 + LIMS（测试报告） | 面料档案卡、测试单、采购单、封样卡 | 物料主数据以PLM为准，ERP同步价格/供应商 |
| 制版 | 制版CAD + 3D样衣联动 | 纸样/放码/唛架/单耗 | 电子版纸样归档PLM+CAD服务器双备 |
| 样衣评审 | PLM评审流 + 会议投屏/拍照归档 | 样衣流转卡、评审打分、PP样确认书、封样卡 | 结论当日录入PLM，纸质单扫描上传 |
| 大货生产 | ERP订单 + MES进度 + 即时通讯日报 | 生产订单、产前会纪要、首件确认、进度日报 | 日产量进MES/ERP，跟单台账挂ERP订单号 |
| 质检入库 | QMS（或PLM质检模块）+ 验针机/拉力计设备数据 + WMS | 三检报告、缺陷照片、入库复检单 | 报告存QMS/PLM，条码/数量进WMS/ERP |

## 5. 操作流程

### 5.1 选型与准入

```
需求提出 → IT+业务联合选型 → 试用验证 → 采购审批 → 上线
```

1. **选型原则**：优先已有生态兼容（CAD↔3D样衣、PLM↔ERP接口），同类软件全公司只保留一套主用+一套备用
2. **试用验证**：至少跑通1个完整款（设计→纸样→样衣→下单→检验）全链路，接口跑通才算通过
3. **License管理**：CAD/3D/Adobe等按 named/user 账号分配，离职24小时内回收；并发数不足先调配闲置许可，确需增购走年度预算

### 5.2 数据标准（跨系统唯一口径）

1. **款号**：全系统统一`年份+季节+品类码+流水号`（如26AW-JK-012），PLM建款后ERP/CAD/QMS禁止自编
2. **物料编码**：`大类+成分+年份+流水`（如F-COT-26-0088），成分/克重/门幅/色号四要素缺一不可建档
3. **版本规则**：工艺单/纸样/封样统一V1/V2递增，旧版自动置灰不可下载生产用；产中变更走ECR后版本+1
4. **颜色**：潘通色号+封样编号双轨，屏幕取色值仅作示意，不作为生产依据

### 5.3 日常运维

1. **账号权限**：设计/制版/跟单/QC按角色授权；供应商（外发厂）仅开当季在制款只读+上传权限，合作终止即关闭
2. **备份**：CAD纸样服务器+PLM每日增量备份，每季度做一次恢复演练
3. **培训**：新软件上线2周内完成全员培训+考核记录；CAD/3D关键岗位要求持证或通过内部定级

## 6. 特殊情况处理

### 6.1 系统故障/断网
- 生产现场切换纸质单（工艺单打印件+手工日报），恢复后24小时内补录，补录单标注“补”字备查

### 6.2 接口中断（PLM↔ERP不同步）
- 以PLM版本为准生产，ERP差异挂账待处理；中断超4小时升级IT负责人，不得两边各改各的

### 6.3 外发厂无对应系统
- 最低要求：Excel标准模板（公司统一下发）+照片/扫描件回传；关键款派驻跟单现场录入

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| PLM建款及时率（设计定稿后2天内） | 100% |
| 跨系统款号/物料一致率 | ≥ 99% |
| 旧版工艺单/纸样误用事故 | 0起 |
| License闲置率 | ≤ 10% |
| 系统故障恢复后补录及时率 | 100%（24h内） |

## 8. 信息安全管理

- 设计稿、纸样、成本数据按密级管理：绝密（未上市款）/机密（成本价）/内部（已上市款），外发 progressively 脱密
- 趋势平台、PLM、CAD账号禁止共用，审计日志保留6个月
- 独家花型/保密版型输出加水印+有效期，超期自动失效

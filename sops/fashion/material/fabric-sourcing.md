## 1. 目的

规范面辅料寻源、确认、测试、采购与入库全流程，确保大货面辅料与确认样一致，色牢度、缩率、甲醛等指标达标，价格与交期满足企划要求。

## 2. 适用范围

适用于主面料、里料、衬、辅料（拉链/纽扣/织带/缝纫线/唛头/包装物）的开发与大货采购。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 头缸/缸差 | 首次染色结果；不同染色批次间的色差 |
| 对色光源 | 评定颜色的标准光源，成衣常用D65+卖场灯双光源 |
| 缩率 | 洗涤/熨烫后尺寸变化率，直接影响制版放缩 |
| 齐色大货 | 所有颜色面料按订单量一次到齐入库 |
| AQL | 可接受质量限，大货面料检验抽样标准 |

## 4. 职责分工

### 4.1 面辅料开发员
- 按工艺单寻源打样，组织面料确认（手感/颜色/成分/克重）
- 建面辅料档案卡，跟进测试与大货回料

### 4.2 设计师
- 确认面料风格、颜色、花型效果是否符合设计意图并签字

### 4.3 采购部
- 议价下单、跟踪交期、对账结算
- 主导供应商准入与年度评估

### 4.4 质检（IQC）
- 执行来料检验与第三方送检，出具放行/拒收结论

## 5. 操作流程

### 5.1 寻源与确认

```
工艺单接收 → 寻源打样 → 设计确认 → 测试 → 封样
```

1. **寻源打样**：每款主面料≥2家比价，A/B角供应商制；打样必须带成分/克重/门幅/单价四要素报价单
2. **设计确认**：颜色以实物色卡+对色光源为准，照片/屏幕色一律无效
3. **必测项目**（大货前完成）：
   - 全品类：成分、色牢度（耐水/耐汗渍/摩擦）、甲醛、pH、异味
   - 棉/麻/粘纤/牛仔：+水洗缩率；针织：+顶破/起球；羽绒：+充绒量/清洁度；防水/冲锋衣：+静水压/透湿
   - 测试不通过不得下大货单，整改重测最多2次
4. **封样**：确认面料正反面各封一块（开发/供应商/质检三方签字），大货来料以封样为唯一比对基准

### 5.2 下单与交期跟踪

```
大货预算确认 → 下单 → 产前头缸确认 → 分批回料 → 入库检验
```

1. **下单**：订单注明成分、克重、门幅、颜色（潘通+封样编号）、数量（含损耗：常规3%-5%，格纹对条/印花5%-8%）、交期、允差标准
2. **头缸确认**：大货首缸/首卷回料先对色对缩，OK后书面放行后续生产（“头缸放行制”）
3. **交期预警**：晚于计划3天黄色预警（启动备选供应商），晚于7天红色预警（升级至供应链总监，评估波段调整）
4. **入库检验**：按AQL 2.5抽检，检验布面疵点、色差（缸差≤4级边际样）、门幅克重偏差、数量；记录布卷号，色差严重卷单独标注、裁剪时分包使用

## 6. 特殊情况处理

### 6.1 来料色差/缩率超标
- 轻微超标：与设计/制版会签，评估改拼色/调整放缩量消化
- 严重超标：整批拒收，供应商限期重做；影响上货则触发企划波段调整流程

### 6.2 供应商临时断供
- 启用A/B角备份供应商；无备份则按封样标准重新寻源+测试，快反款测试可压缩但不可跳过甲醛/pH/色牢度三项

### 6.3 价格超预算
- 先走替换（同风格低价位面料）→再走议价（拼单/期货锁价）→最后申请特批；禁止先下单后补批

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 面料测试一次通过率 | ≥ 85% |
| 头缸确认执行率 | 100% |
| 来料检验覆盖率 | 100% |
| 大货与封样一致率 | ≥ 98% |
| 回料准时率（相对大货排期） | ≥ 95% |

## 8. 信息安全管理

- 供应商报价单、采购价为机密，设计/质检环节隐去价格列
- 独家开发花型/面料签保密与排他协议，未经批准不得向第三方提供

## 1. 目的

规范纸样/电子版制作、放码、排料与缝制工艺标准，确保版型稳定、上身效果与设计意图一致，样衣与大货工艺可复制。

## 2. 适用范围

适用于梭织、针织、毛衫、牛仔、羽绒五大类产品的制版与工艺管理。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 头版/复版 | 第一版样衣纸样；按意见修改后的第二版及以后 |
| 放码（推档） | 由基准码推放全码纸样 |
| 唛架（排料图） | 裁剪排料方案，决定单耗与对条对格效果 |
| 倒顺/阴阳 | 面料方向性差异（绒面/印花方向），排料必须同向 |
| 止口/缝份 | 缝合预留宽度，不同部位标准不同 |

## 4. 职责分工

### 4.1 制版师
- 按工艺单制版放码，输出纸样/电子版+尺寸表+用料单
- 参加试版，记录改版数据并更新档案

### 4.2 样衣工
- 按纸样与工艺要求制作样衣，反馈实操难点与工时

### 4.3 设计师
- 确认版型风格（廓形/比例/松量），签字放行

### 4.4 工艺员
- 编制大货缝制工艺单（SOP工位分解、线迹/针距/熨烫要求），核算标准工时（SAM）

## 5. 操作流程

### 5.1 制版

```
工艺单审核 → 纸样制作 → 试版 → 改版 → 纸样确认归档
```

1. **接单审核**：工艺单缺尺寸表/面料缩率/辅料清单任一项即退回，制版不接“口头版”
2. **纸样制作**：
   - 基准码：女装M（160/84A）、男装L（175/92A），特体款另定
   - 必含信息：款号、码号、裁片名、丝缕线、剪口/钻眼、对位标记、缝份
   - 电子版统一用CAD归档，纸样实物保留至大货出货后6个月
3. **试版**：样衣上身检查三点——廓形比例（肩/胸/腰/摆）、活动量（抬臂/下蹲/坐）、对称性（左右/前后）
4. **改版记录**：每次改版标注日期+改动部位+数据，保留历史版备查，禁止原版上直接涂改覆盖

### 5.2 放码与排料

```
基准码确认 → 全码放码 → 唛架制作 → 单耗核定
```

1. **放码**：全码至少抽检首尾两码做实物验证；牛仔/水洗产品放码必须计入水洗缩率
2. **唛架**：格纹/条纹标注对条要求，印花标注主花位，绒面/倒顺面料标注同向；唛架利用率目标≥85%
3. **单耗核定**：以唛架实测+3%-8%损耗核定大货单耗，作为采购与成本结算依据

### 5.3 大货工艺编制

```
产前样确认 → 工位分解 → 针法线迹标准 → 产前会交底
```

- 线迹标准示例：侧缝/肩缝四线包缝+单明线，针距3cm 12-14针；衬衫摆缝0.6cm双折边；羽绒服充绒格走线偏差≤0.2cm
- 熨烫/定型：西装/大衣必须有半成品试烫记录；针织平铺定型，禁止悬挂烘干变形
- 标准工时（SAM）作为加工费核算与排期依据，产前冻结，产中不得随意加价

## 6. 特殊情况处理

### 6.1 设计与版型冲突（廓形无法落地）
- 制版48小时内书面反馈风险+替代方案（改省道/加拼接/换衬），由设计师二选一签字

### 6.2 面料缩率与预估不符
- 按实测缩率重调纸样；已裁样衣报废不计入改版轮次，但需记录原因追溯面料责任

### 6.3 产前临时改版
- 上货前30天内冻结版型；冻结后改版必须走ECR（工程变更）审批：评估面辅料损失+交期影响，三方签字方可执行

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 工艺单退单率（缺件退回） | 有记录可查，目标逐季下降 |
| 头版一次吻合率（尺寸在允差内） | ≥ 80% |
| 放码全码尺寸合格率 | 100% |
| 唛架利用率 | ≥ 85% |
| 纸样档案完整率 | 100% |

## 8. 信息安全管理

- 纸样电子版按款号权限管理，兼职制版到期即回收账号
- 爆款版型列为保密版，纸样借阅登记，禁止拍照外发

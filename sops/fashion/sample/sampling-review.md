## 1. 目的

规范头版样、复版样、齐色样、产前样（PP样）、封样（Sealed样）五级样衣管理，明确评审通过标准，确保进入订货会与大货的款都是“可生产、可销售、可盈利”的款。

## 2. 适用范围

适用于季度开发全部样衣与季中快反样衣。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 头版样 | 验证版型廓形的第一件样衣，面料可代用 |
| 齐色样 | 一款所有颜色各一件，用于评审配色效果 |
| PP样（产前样） | 大货面辅料+大货工艺的第一件，用于产前确认 |
| 封样 | 三方签字封存的最终标准样，大货验收唯一基准 |
| 评审通过率 | 提报评审款中直接通过+有条件通过的占比 |

## 4. 职责分工

### 4.1 样衣间主管
- 排样衣计划（按波段优先级），分配样衣工，考核样衣准时率与返工率

### 4.2 样衣工
- 按工艺单与纸样制作样衣，记录实际工时与难点

### 4.3 设计师
- 全程跟样，提出改版意见并更新工艺单

### 4.4 评审委员会（商品+设计+营销+供应链）
- 样衣评审投票：通过/修改后通过/淘汰；封样三方签字

## 5. 操作流程

### 5.1 样衣制作

```
排期 → 头版 → 复版 → 齐色 → PP样 → 封样
```

1. **排期**：按“主推系列优先、长交期面料优先”排序；常规样衣周期头版3-5天、复版2-3天
2. **做样要求**：
   - 头版可用代用布，但廓形与结构必须一致；齐色样起必须用大货面料
   - 样衣挂吊牌：款号+版次+日期+制版/样衣工姓名，全程可追溯
   - 每版样衣 cry？不，保留历史版：评审现场必须能看到头版→复版演变
3. **PP样**：大货面辅料到齐后第一时间做，验证真实缩率、水洗效果、辅料 compatibility；PP样不通过不得开裁大货

### 5.2 样衣评审会（订货前）

```
齐色样陈列 → 设计讲解 → 上身试穿 → 投票 → 定价与下单建议
```

1. **陈列**：按系列+波段陈列，配企划色卡与预估零售价签
2. **评审维度**（每维度 pass/conditional/fail）：
   - 企划符合度（品类/价格带/主题）
   - 上身效果（廓形/显瘦显高/舒适度，试穿员覆盖S-XL至少3个码）
   - 成本毛利（成本率超红线必须有明确溢价理由或降本路径）
   - 可生产性（工艺复杂度、工厂产能、交期）
3. **结论处理**：
   - 通过：进入订货会
   - 有条件通过：限期整改项（如换纽扣/调配色/降成本），复核人签字后放行
   - 淘汰：样衣归档，工艺单标注淘汰原因，面料转备选库
4. **定价**：评审会同步冻结零售价与吊牌价，冻结后调价走特批

### 5.3 封样管理

- 封样一式三份：公司档案、工厂、大货QC各一，全部签字+拍照存档
- 封样变更走ECR，旧封样标注作废日期，新封样重新编号（如V2）

## 6. 特殊情况处理

### 6.1 样衣延期
- 延期超3天自动升级：样衣主管+设计师+面料员三方会诊，方案二选一：换代用布先走版/调整评审批次

### 6.2 评审意见冲突（设计坚持 vs 商品否决）
- 以数据裁决：调取同类款历史售罄率/退货率，商品总监有一票否决权，设计可申请总经理特批

### 6.3 PP样与封样不一致
- 以封样为准大货返工；属工厂擅自变更的，按合同扣款并记入供应商评估

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 样衣准时交付率 | ≥ 95% |
| 评审结论当场输出率 | 100%（不隔夜） |
| 有条件通过项按期关闭率 | 100% |
| PP样确认后开裁率 | 100%（无样先裁为红线事故） |
| 封样三方签字完整率 | 100% |

## 8. 信息安全管理

- 评审现场禁止拍照外发；订货会前款式图为绝密
- 淘汰款设计稿归档不销毁，防止外部抄袭举证缺失

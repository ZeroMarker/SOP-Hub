## 1. 目的

规范从创意提案到设计定稿的全流程，确保款式符合企划案（品类/价格带/主题）、图稿工艺可落地、设计资料一次交齐，减少样衣反复与产前改版。

## 2. 适用范围

适用于季度新款设计开发与季中补充款快反设计。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 系列 | 同一主题故事下的款式组合，通常5-15款 |
| 设计稿 | 正面款式图+背面图+细节图，标注工艺与配色 |
| 工艺单 | 交制版/样衣的正式生产指令文件，含尺寸表、辅料清单、做工要求 |
| 齐色 | 一款多色确认，所有颜色面辅料一次到齐 |
| 企划符合度 | 实际设计与企划案在品类、价格带、主题上的一致程度 |

## 4. 职责分工

### 4.1 主任设计师
- 分配系列任务，审核组员设计稿与工艺单
- 主持内部初审，决定提报评审会的款

### 4.2 设计师/助理设计师
- 完成趋势提案、设计稿、配色、工艺单
- 跟进样衣进度，记录改版意见并更新资料

### 4.3 商品企划
- 确认款式归属品类/波段/价格带，核算预估成本率
- 对偏离企划的设计行使否决或特批

### 4.4 制版师/样衣工
- 反馈图稿工艺可行性与风险点
- 按工艺单制版做样，记录实际用料与工时

## 5. 操作流程

### 5.1 创意提案与任务分配

```
企划下发 → 趋势提案 → 系列分工 → 设计初稿
```

1. **趋势提案**：每系列输出灵感板（moodboard）+廓形/色彩/面料/图案四要素说明
2. **任务分配**：按设计师擅长品类分配款量，主推系列安排双人互审
3. **初稿要求**：
   - 正反款式图+至少1处细节放大图
   - 标注：面料方向、印绣花位置尺寸、特殊工艺（压褶/水洗/破洞等）
   - 每款附建议零售价测算（面料预估单价×单耗+工费倒推）

### 5.2 内部初审与工艺单输出

```
设计初稿 → 内部初审 → 工艺单编制 → 资料交接
```

1. **内部初审**：淘汰重复款、超成本无替代方案款、工艺不可落地款
2. **工艺单编制**（一稿一单，必填项）：
   - 款号规则：`年份+季节+品类码+流水号`（如26AW-JK-012）
   - 内容：款式图、号型尺寸表（覆盖XS-XL/ S-2XL全档）、面辅料清单（含色号/克重/成分）、缝制要求、印绣花文件、包装要求
   - 成本栏：预估单耗、面辅料单价、加工费三项必填
3. **资料交接**：工艺单+设计稿+花型文件一次性交制版，缺件不接单

### 5.3 样衣跟进与设计定稿

```
头版样衣 → 设计确认 → 复版/齐色 → 设计定稿签字
```

1. **头版确认**：设计师上身试穿确认廓形、比例、穿着舒适度，意见当场写在样衣确认单上，不允许口头传达
2. **复版**：按改版意见第二轮样衣，原则上不超过2轮；超2轮需主任设计师审批并记录原因
3. **定稿签字**：设计师+制版师+商品企划三方签字，任一方未签字不得进入订货评审

## 6. 特殊情况处理

### 6.1 快反补充款
- 可跳过系列提案，直接以“对标款+改良点”立项
- 工艺单允许暂缺全档尺寸，先出主销码做样，全档在产前补齐

### 6.2 设计稿与成本冲突
- 成本超红线时优先顺序：替换面料→简化工艺→调整价格带→申请特批
- 不得私自降低里料/辅料规格降成本，必须明示变更

### 6.3 花型/印花版权争议
- 外购花型必须附授权链文件，原创花型归档底稿+创作记录
- 无版权证明的花型一律不得上样衣评审

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 工艺单一次交齐率 | ≥ 95% |
| 头版一次通过率 | ≥ 60%（统计口径：无需结构性改版） |
| 样衣改版轮次 | 常规款 ≤ 2轮 |
| 设计定稿准时率（相对波段排期） | ≥ 95% |
| 定稿三方签字完整率 | 100% |

## 8. 信息安全与知识产权管理

- 设计稿、花型文件统一存档于公司网盘，禁止个人网盘/微信传源文件
- 离职交接必须移交全部在研款工艺单与花型源文件
- 对外（供应商/兼职制版）仅提供当款必要图纸，整季系列图不外发

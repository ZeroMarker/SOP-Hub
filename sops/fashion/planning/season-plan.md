## 1. 目的

规范季度商品企划全流程，确保趋势研判、品类规划、波段排期与OTB预算相互咬合，使设计开发有明确的款量、价格带、上市节奏依据，降低盲目开发与滞销风险。

## 2. 适用范围

适用于春夏/秋冬两大季（及季中补充波段）的商品企划、色彩企划、价格带规划全过程。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| OTB | 期货采购预算，限定各品类/波段可下单金额 |
| 波段 | 按上市时间划分的上货批次，如第一波段（季初）、第二波段（季中） |
| SKU / SPU | SKU为最小售卖单位（款+色+码），SPU为款式单位 |
| 价格带 | 按零售价划分的档位，如引流带、主力带、形象带 |
| 色彩企划 | 每季主推色、辅助色、基础色的组合与配比规定 |
| 款量结构 | 各品类（外套/上装/下装/裙/配饰）款数与SKU占比 |

## 4. 职责分工

### 4.1 商品企划（主责）
- 输出季度企划案：波段节奏、品类款量、价格带、OTB分解
- 跟踪开发进度与企划符合度，组织企划评审会
- 上市后做动销复盘，输出季中调整建议

### 4.2 设计部
- 提供趋势提案与款式方向建议
- 按企划案认领款量并做设计开发

### 4.3 面辅料开发
- 反馈当季可落实的面料资源与成本区间
- 配合色彩企划做染色/印花可行性确认

### 4.4 营销/销售部
- 提供上季销售数据、会员画像与渠道反馈
- 确认各波段上货量与促销节点

## 5. 操作流程

### 5.1 趋势与复盘输入

```
上季销售复盘 → 趋势调研 → 企划初案
```

**详细步骤：**

1. **上季复盘**（上市前8个月）：
   - 输出畅滞销款TOP/BOTTOM分析：版型、颜色、价格、面料维度
   - 输出售罄率、连带率、退货率（版型/质量原因单独统计）
   - 沉淀可延续版型库与淘汰清单
2. **趋势调研**：
   - 流行资讯（WGSN/ popbee等）、订货会走访、标杆品牌上新跟踪
   - 输出趋势报告：廓形、工艺、色彩、面料、图案五要素
   - 趋势提案必须标注来源与预计流行周期（快流行/长青）
3. **企划初案**：
   - 确定主题故事线（1个大主题+2-3个小系列）
   - 初定品类款量、SKU数、价格带矩阵

### 5.2 企划案编制与评审

```
波段排期 → 价格带与OTB分解 → 色彩企划 → 企划评审会 → 企划定稿下发
```

**详细步骤：**

1. **波段排期**：
   - 按上市日历倒排：设计定稿→面辅料到仓→样衣确认→大货下单→上货
   - 每波段明确上货日期、SKU数、主推系列
   - 季中补充波段预留10%-15% OTB机动额度
2. **价格带与OTB分解**：
   - 价格带占比建议：引流带10%-15%、主力带60%-70%、形象带10%-15%
   - OTB按品类×波段二维表分解，成本率红线（如成衣成本率≤25%）同步下发
   - 超成本款需在企划阶段即标记，走特批或替换方案
3. **色彩企划**：
   - 每款限定色数（常规款3-4色，主推款可放宽至5色）
   - 主推色全品类贯穿，辅助色按系列走，基础色（黑/白/灰/藏青）保底
   - 输出色卡（含潘通色号+面料实物色卡），设计与面料共用一套
4. **企划评审会**：
   - 参与方：商品总监、设计总监、营销负责人、供应链负责人
   - 评审点：款量是否超产能、价格带是否覆盖客群、主题故事是否可讲
   - 结论三类：通过/有条件通过（限期整改项）/驳回重做

### 5.3 企划执行跟踪

```
企划下发 → 开发进度对账 → 上市前符合度检查 → 动销复盘
```

1. **双周对账**：实际开发款数/企划款数偏差超过10%即预警
2. **符合度检查**：样衣评审前核对款式是否偏离企划（品类挪用、价格带漂移）
3. **动销复盘**：上市4周、8周各一次，输出补单/砍单/调价建议

## 6. 特殊情况处理

### 6.1 趋势突变（明星同款/突发热点）
- 启动快反通道：企划+设计+供应链48小时内评估是否追单
- 快反款不占用常规波段款量，单独走快反OTB（占比≤10%）

### 6.2 核心面料交付延期
- 优先替换同企划色系备选面料，保波段上货日期
- 无法替换则整系列顺延，不得拆散系列零散上货

### 6.3 OTB超支
- 按“砍滞销预期款、保畅销延续款”顺序削减
- 任何超OTB下单必须商品总监书面特批

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 企划案按时下发率 | 100%（不晚于开发启动日） |
| 开发符合度（款式归属品类/波段一致） | ≥ 95% |
| 价格带覆盖完整率 | 100%（无空档价格带） |
| 色彩企划执行一致率 | ≥ 90% |
| 上市4周售罄率复盘输出及时率 | 100% |

## 8. 信息安全管理

- 季度企划案、OTB金额、成本率为核心商业机密，仅限评审会成员传阅
- 趋势报告付费账号专人专用，禁止外发截图
- 上市前款式图、色卡对外（供应商）分段提供，整盘企划不外泄

## 1. 目的

规范成衣产前、产中、尾期三段检验与入库标准，确保出运成衣与封样一致，外观、尺寸、功能、包装达标，不合格品不流入门店。

## 2. 适用范围

适用于所有自有工厂与外发工厂的大货成衣检验与仓库入库。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| AQL | 可接受质量限；成衣尾期常规执行AQL 2.5，形象款/高端线收紧至1.5 |
| 致命/严重/轻微缺陷 | 致命：安全法规项（断针/甲醛/小部件脱落）；严重：影响销售（破洞/色差/尺寸超差）；轻微：不明显线头/轻微污渍可返修 |
| 限度样 | 缺陷可接受边界的实物样，张贴于工厂QC台 |
| 尾期检验 | 大货包装前按抽样方案的最终检验 |
| 入库复检 | 仓库按比例开箱复核数量与包装 |

## 4. 职责分工

### 4.1 QC组长
- 制定检验计划，签发放行/返修/拒收结论，管理限度样与封样

### 4.2 现场QC
- 执行三检并出具报告，现场标示缺陷品（贴箭头贴+隔离区）

### 4.3 跟单员
- 协调工厂返修档期，跟踪复检关闭

### 4.4 仓库
- 执行入库复检：数量、外箱唛头、防潮防压，系统入库上架

## 5. 操作流程

### 5.1 检验准备

```
封样+工艺单领取 → 限度样确认 → 检验工具准备 → 检验计划通知工厂
```

- 检验工具：验针器（必过检，全件过机）、拉力计（纽扣/小部件≥90N，童装≥50N+洗后复测）、色卡/灯箱、对色布、钢尺
- 尾期检验要求：大货完成≥80%且已包装≥50%方可申请，工厂自检报告先行提交

### 5.2 三段检验标准

**产前检验（开裁前）：**
- 核对面辅料齐套、色卡、封样版本是否为最新
- 唛架复核：对条对格、方向、利用率

**产中检验（缝制中期，约20%-30%产量）：**
- 首件全检+流水抽检，重点：止口宽度、针距、左右对称、辅料位置
- 发现系统性问题（同一缺陷≥5%）即停线整改，已制品全检返修

**尾期检验（包装前）：**
- 抽样方案：按AQL 2.5（批量≤500抽50，501-1200抽80，1201以上抽125， industry惯例可参照GB/T 2828.1）
- 必检项：
  - 外观：色差（同件前后/左右≤4级）、污渍、破洞、抽丝、烫黄烫亮
  - 尺寸：关键部位（胸围/衣长/裤长）允差±1.0cm，次要部位±1.5cm；每色每码至少量1件
  - 功能：拉链顺滑10次、纽扣牢度、缝口纰裂（≥6mm扣重）、水洗色牢度抽测
  - 安全：断针检验全件过机（9点灵敏度），童装绳带/小部件按GB 31701执行
  - 包装：吊牌/价格/条码一一对应，折叠方式统一，箱唛与装箱单一致
- 结论：合格放行；返修（限期复检）；拒收（退回工厂全检+二次申请）

### 5.3 入库复检

```
到仓预约 → 开箱抽检（≥10%）→ 数量/条码核对 → 系统入库 → 上架/发店
```

- 数量差异>0.5%或条码错误即整单冻结，通知跟单与工厂对账
- 受潮/压变形/异味整箱拒收，单独存放待处理

## 6. 特殊情况处理

### 6.1 断针/金属残留
- 红线事故：涉事纸箱全部隔离，整批过机复检；查明断针工位，保留记录追溯责任

### 6.2 色差批量事故
- 按“分包上市”（深浅分店）或“整批降级”（转奥莱/员工购）处理，禁止混包发往同一店铺

### 6.3 上市紧急放行
- 仅允许轻微缺陷让步放行：QC组长+商品总监双签，缺陷清单随货告知销售（挂牌价保、优先陈列遮瑕面），致命/严重缺陷永不让步

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 尾期检验覆盖率 | 100%（无检验放行出运为红线） |
| 验针全件通过率 | 100% |
| 尺寸抽检合格率 | ≥ 98% |
| 入库条码准确率 | 100% |
| 客诉率（质量原因退货） | ≤ 2% |

## 8. 信息安全管理

- 检验报告、缺陷照片存档至品质系统，保留至该季售罄后1年
- 工厂质量评分（返修率/拒收次数）按季度通报，年度评估末位淘汰

## 1. 目的

规范手卫生设施配置、手卫生时机、操作方法、监测反馈和持续改进要求，降低医院感染发生风险，保障患者和医务人员安全。

## 2. 适用范围

适用于全院诊疗、护理、检验、检查、手术、清洁消毒、患者转运等所有可能发生交叉感染风险的工作场景。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 手卫生 | 洗手、卫生手消毒和外科手消毒的总称 |
| 洗手 | 使用流动水和洗手液去除手部污垢和部分微生物 |
| 卫生手消毒 | 使用速干手消毒剂减少手部暂居菌的过程 |
| 外科手消毒 | 手术前按规范清除或杀灭手部暂居菌并减少常居菌 |
| 手卫生依从性 | 实际执行手卫生次数占应执行次数的比例 |

## 4. 职责分工

### 4.1 医院感染管理科
- 制定手卫生制度和操作规范
- 组织培训、督导和依从性监测
- 分析监测结果并推动整改

### 4.2 科室负责人
- 落实本科室手卫生管理要求
- 配备并维护手卫生设施
- 督促人员按规范执行

### 4.3 医务人员
- 按规定时机和方法执行手卫生
- 保持手部皮肤清洁、指甲短洁
- 发现设施缺失或故障及时上报

### 4.4 后勤/保洁人员
- 保持洗手设施清洁可用
- 及时补充洗手液、擦手纸和手消毒剂
- 按要求执行清洁工作中的手卫生

## 5. 操作流程

### 5.1 手卫生时机

```
接触患者前 → 清洁/无菌操作前 → 接触体液后
→ 接触患者后 → 接触患者周围环境后
```

**必须执行场景：**

- 进行注射、换药、导尿、吸痰等操作前后
- 接触血液、体液、分泌物、排泄物后
- 接触不同患者之间
- 戴手套前和脱手套后
- 进入和离开隔离病房时

### 5.2 洗手流程

```
湿手 → 取洗手液 → 按七步洗手法揉搓 → 流动水冲洗
→ 一次性擦手纸擦干 → 关闭水龙头
```

**操作要求：**

- 揉搓时间不少于 15 秒
- 覆盖掌心、手背、指缝、指背、拇指、指尖和腕部
- 手部有可见污染时必须洗手，不得仅使用手消毒剂替代

### 5.3 卫生手消毒流程

```
取适量手消毒剂 → 覆盖双手所有表面 → 按七步法揉搓
→ 自然干燥
```

**操作要求：**

- 手消毒剂用量应足以保持揉搓期间双手湿润
- 揉搓至完全干燥
- 不得用纸巾擦干未干的手消毒剂

### 5.4 外科手消毒流程

```
摘除饰物 → 清洁指甲 → 洗手和前臂 → 外科手消毒
→ 保持手高于肘部 → 穿无菌手术衣和戴无菌手套
```

**操作要求：**

- 按手术室外科手消毒规范执行
- 不得佩戴戒指、手表、手链和假指甲
- 手部皮肤破损应评估是否适合参与手术

### 5.5 监测改进流程

```
制定监测计划 → 现场观察 → 数据统计 → 结果反馈
→ 原因分析 → 整改追踪
```

**监测内容：**

- 手卫生依从性
- 手卫生正确率
- 手卫生用品可及性
- 重点科室和重点岗位执行情况

## 6. 特殊情况处理

### 6.1 手卫生用品短缺
- 科室立即补充或申请
- 感控人员追踪短缺原因
- 影响诊疗安全时暂停相关操作

### 6.2 职业暴露后
- 立即按职业暴露流程处理
- 清洗或消毒污染部位
- 上报医院感染管理科

### 6.3 隔离患者接触
- 进入隔离区域前后必须执行手卫生
- 按隔离类别选择防护用品
- 脱防护用品过程中按流程执行手卫生

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 手卫生依从率 | 持续提升，重点部门 ≥ 90% |
| 手卫生正确率 | ≥ 95% |
| 手卫生设施完好率 | 100% |
| 手卫生用品可及率 | 100% |
| 新员工培训覆盖率 | 100% |
| 监测反馈完成率 | 100% |

## 8. 信息安全管理

- 监测结果用于质量改进，公开反馈时避免泄露个人隐私
- 感染暴发相关信息按医院规定上报
- 培训和监测记录按院感资料归档

## 1. 目的

规范临床检验标本采集、标识、保存、转运和接收流程，保障标本质量，减少检验前误差，确保检验结果准确可靠。

## 2. 适用范围

适用于血液、尿液、粪便、痰液、分泌物、体液及其他临床检验标本的采集和送检。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 检验前质量控制 | 从医嘱开具到标本上机检测前的质量管理活动 |
| 标本容器 | 用于采集和保存检验标本的试管、杯、瓶等器具 |
| 条码标识 | 包含患者身份、检验项目和采集信息的唯一识别码 |
| 拒收标本 | 因不符合检验要求而不能检测的标本 |
| 危急值 | 检验结果提示患者可能存在生命危险、需立即处理的异常值 |

## 4. 职责分工

### 4.1 开单医师
- 正确开具检验医嘱
- 告知患者采集注意事项
- 接收并处理危急值报告

### 4.2 采集人员
- 核对患者身份和检验项目
- 按规范采集、标识和保存标本
- 处理采集异常并记录

### 4.3 检验科接收人员
- 接收、核对和登记送检标本
- 判断标本是否合格
- 对不合格标本执行拒收和反馈

### 4.4 标本转运人员
- 按规定时间和条件转运标本
- 保持转运箱清洁和温控要求
- 完成交接记录

## 5. 操作流程

### 5.1 标本采集流程

```
医嘱确认 → 患者身份核对 → 采集准备 → 标本采集
→ 条码粘贴 → 标本保存 → 送检登记
```

**详细步骤：**

1. **医嘱确认**：
   - 核对检验项目、标本类型和采集时间
   - 确认是否空腹、停药或特殊准备
   - 确认容器类型和采集量

2. **身份核对**：
   - 使用姓名、年龄、门诊号/住院号等至少两项信息核对
   - 住院患者核对腕带
   - 不得凭床号单独确认身份

3. **采集准备**：
   - 准备采血针、试管、容器、消毒用品和防护用品
   - 检查容器有效期和完整性
   - 向患者解释采集目的和注意事项

4. **标本采集**：
   - 严格执行无菌操作和手卫生
   - 按项目要求控制采集量、采集部位和采集时间
   - 抗凝管采血后按要求轻柔颠倒混匀

5. **标识保存**：
   - 采集后立即粘贴条码
   - 标本标签不得遮挡液面和刻度
   - 按项目要求避光、冷藏或常温保存

### 5.2 标本转运流程

```
标本整理 → 转运箱放置 → 交接登记 → 定时转运
→ 检验科接收 → 异常反馈
```

**转运要求：**

- 血常规、生化等常规标本按规定时限送检
- 凝血、血气、脑脊液等特殊标本优先送检
- 标本容器保持密闭，避免污染和泄漏
- 感染性标本使用符合要求的密封袋和标识

### 5.3 标本接收流程

```
接收扫描 → 信息核对 → 标本质量检查 → 合格接收
→ 不合格拒收 → 反馈重采
```

**拒收标准：**

- 患者信息不符或条码缺失
- 标本量不足、容器错误或采集时间错误
- 严重溶血、凝血、污染或泄漏
- 超过稳定保存时间
- 特殊项目未按要求保存或转运

## 6. 特殊情况处理

### 6.1 采血困难
- 更换采血部位或请经验丰富人员协助
- 不得反复穿刺超过医院规定次数
- 必要时通知医师调整采集方案

### 6.2 患者晕针或不适
- 立即停止采集并协助患者平卧
- 观察生命体征
- 必要时通知医师处理并记录

### 6.3 标本遗失或破损
- 立即上报检验科和临床科室
- 记录遗失或破损原因
- 与患者沟通并安排重采

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 患者身份核对率 | 100% |
| 标本条码粘贴正确率 | ≥ 99.5% |
| 标本拒收率 | 持续监测并月度分析 |
| 标本送检及时率 | ≥ 98% |
| 采集不良事件上报率 | 100% |
| 危急值通知及时率 | 100% |

## 8. 信息安全管理

- 标本标签和检验申请单不得随意丢弃
- 检验结果仅向授权医护人员和患者本人提供
- 采集系统账号专人专用
- 涉及传染病信息按相关规定上报和保密

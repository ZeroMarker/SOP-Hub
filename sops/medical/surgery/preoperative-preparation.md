## 1. 目的

规范手术患者术前评估、知情同意、检查准备、身份核对和交接流程，降低手术风险，保障患者安全。

## 2. 适用范围

适用于择期手术、限期手术和急诊手术患者术前准备管理。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 术前评估 | 对患者病情、手术适应证、麻醉风险和围术期风险进行综合评估 |
| 手术安全核查 | 在麻醉前、手术开始前、患者离室前进行的安全确认 |
| 知情同意 | 医务人员向患者或家属说明手术风险、替代方案并取得书面同意的过程 |
| 手术部位标识 | 对手术侧别或部位进行明确标记，防止错误手术 |
| 禁食禁饮 | 术前按麻醉要求停止进食和饮水 |

## 4. 职责分工

### 4.1 主管医师
- 完成手术适应证评估和术前讨论
- 进行手术知情告知并签署同意书
- 开具术前医嘱并确认检查结果

### 4.2 麻醉医师
- 完成麻醉术前访视和风险评估
- 制定麻醉方案
- 进行麻醉知情告知

### 4.3 病区护士
- 执行术前医嘱和护理准备
- 完成皮肤准备、禁食禁饮宣教和物品核对
- 与手术室进行患者交接

### 4.4 手术室护士
- 核对患者身份、手术信息和同意文件
- 准备手术间、器械和耗材
- 参与手术安全核查

## 5. 操作流程

### 5.1 术前评估流程

```
手术申请 → 病情评估 → 检查检验完善 → 术前讨论
→ 麻醉评估 → 手术排台
```

**评估内容：**

- 手术诊断、适应证和禁忌证
- 既往病史、过敏史、用药史和手术史
- 心肺功能、凝血功能、感染风险
- 影像学和实验室检查结果
- 血液制品准备需求

### 5.2 知情同意流程

```
告知手术方案 → 说明风险和替代方案 → 解答疑问
→ 患者/家属确认 → 签署同意书 → 文书归档
```

**告知要求：**

- 手术目的、方式、预期效果
- 可能并发症和风险
- 麻醉方式和麻醉风险
- 替代治疗方案和不手术风险
- 费用、植入物或特殊耗材说明

### 5.3 病区术前准备流程

```
执行术前医嘱 → 禁食禁饮宣教 → 皮肤准备 → 术前用药
→ 资料核对 → 物品准备 → 送手术室
```

**准备内容：**

- 核对腕带、病历、影像资料、同意书
- 按医嘱执行备皮、灌肠、导尿等准备
- 移除首饰、义齿、隐形眼镜和贵重物品
- 确认过敏标识、手术部位标识和禁食禁饮状态
- 准备术中用药、血制品和特殊器械需求

### 5.4 手术室接收流程

```
患者到达 → 双方交接 → 身份核对 → 资料核对
→ 手术部位确认 → 麻醉前核查
```

**交接内容：**

- 患者姓名、住院号、手术名称、手术部位
- 过敏史、感染标识、特殊风险
- 术前用药、禁食禁饮、备血情况
- 病历资料、影像资料、同意书

## 6. 特殊情况处理

### 6.1 急诊手术
- 以抢救生命为优先
- 必要检查和同意手续可同步进行
- 术后补齐相关记录和审批

### 6.2 检查结果异常
- 主管医师评估是否暂停手术
- 必要时请相关专科会诊
- 调整方案后重新确认手术安排

### 6.3 手术部位或术式不一致
- 立即暂停接台流程
- 由主管医师、麻醉医师、手术室护士共同核实
- 信息一致后方可继续

## 8. 信息安全管理

- 手术安排和患者病情信息仅限相关人员查看
- 手术影像和病历资料按医疗文书管理
- 患者隐私部位操作注意遮挡和保护
- 手术室信息系统账号专人专用

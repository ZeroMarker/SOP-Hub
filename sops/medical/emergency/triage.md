## 1. 目的

规范急诊患者预检分诊流程，快速识别危急重症患者，合理安排就诊优先级，保障急诊救治安全、有序、高效开展。

## 2. 适用范围

适用于所有到急诊科就诊的患者，包括自行来院、120 转运、院内转诊及突发公共卫生事件相关患者。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 预检分诊 | 根据患者症状、生命体征和危险因素判断病情急缓并安排就诊顺序的过程 |
| 急诊分级 | 将急诊患者按危急程度划分为不同优先级的管理方法 |
| 绿色通道 | 对危急重症患者优先检查、治疗、抢救和办理手续的流程 |
| 生命体征 | 体温、脉搏、呼吸、血压、血氧饱和度等基础指标 |
| 二次分诊 | 患者等待期间因病情变化再次评估和调整分级的过程 |

## 4. 职责分工

### 4.1 分诊护士
- 接诊患者并进行快速评估
- 测量生命体征并记录分诊信息
- 判断急诊分级并安排就诊区域
- 对等待患者进行二次观察

### 4.2 急诊医师
- 接收分诊患者并进行诊疗
- 对危急重症患者立即实施抢救
- 指导分诊护士处理特殊情况

### 4.3 导诊人员
- 维持候诊秩序
- 引导患者至相应区域
- 协助老年人、儿童、残障患者就诊

### 4.4 急诊科负责人
- 制定和维护分诊标准
- 组织培训、质控和应急演练
- 处理分诊争议和突发事件

## 5. 操作流程

### 5.1 预检分诊流程

```
患者到达 → 初步观察 → 身份登记 → 生命体征测量
→ 病情询问 → 分级判断 → 区域引导 → 分诊记录
```

**详细步骤：**

1. **初步观察**：
   - 观察意识状态、呼吸、面色、疼痛和出血情况
   - 发现心跳呼吸骤停、休克、严重创伤等情况立即启动绿色通道

2. **身份登记**：
   - 核对患者姓名、性别、年龄、联系方式
   - 身份不明患者按无名氏流程登记
   - 120 转运患者接收院前交接信息

3. **生命体征测量**：
   - 测量 T、P、R、BP、SpO2
   - 儿童、孕产妇、老年人需关注特殊风险
   - 异常指标立即报告急诊医师

4. **病情询问**：
   - 主诉、起病时间、诱因、伴随症状
   - 既往病史、过敏史、用药史
   - 外伤患者询问受伤机制和时间

5. **分级判断**：
   - 按医院急诊分级标准确定就诊优先级
   - 分级结果、时间、分诊护士签名应完整记录

### 5.2 分级处置流程

| 级别 | 定义 | 处置要求 |
|------|------|----------|
| I级 | 濒危，生命体征极不稳定 | 立即进入抢救室 |
| II级 | 危重，存在生命危险可能 | 10 分钟内诊治 |
| III级 | 急症，病情可能加重 | 30 分钟内诊治 |
| IV级 | 非急症，病情相对稳定 | 按顺序候诊 |

### 5.3 候诊观察流程

```
候诊登记 → 定时巡视 → 病情观察 → 二次分诊
→ 分级调整 → 记录更新
```

**观察要求：**

- III级患者至少每 30 分钟观察一次
- IV级患者至少每 60 分钟观察一次
- 出现胸痛、呼吸困难、意识改变、持续高热、剧烈疼痛等情况立即复评

### 5.4 绿色通道流程

```
危急识别 → 呼叫医师 → 进入抢救室 → 先救治后补手续
→ 多学科协同 → 记录补录
```

**适用情况：**

- 心跳呼吸骤停
- 急性胸痛疑似心梗
- 急性卒中疑似患者
- 严重创伤、大出血、休克
- 严重过敏、窒息、中毒

## 6. 特殊情况处理

### 6.1 群体伤或突发事件
- 启动急诊应急预案
- 按红、黄、绿、黑标识进行现场分流
- 及时报告医务科和医院总值班

### 6.2 无陪护或身份不明患者
- 先救治，后补办身份和费用手续
- 记录体貌特征、随身物品和送诊人员信息
- 必要时联系公安或民政部门

### 6.3 患者拒绝分诊安排
- 解释分诊依据和候诊顺序
- 记录沟通情况
- 争议无法解决时请急诊负责人协调

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 预检分诊完成时间 | ≤ 5 分钟 |
| I级患者抢救响应 | 立即响应 |
| II级患者诊治时间 | ≤ 10 分钟 |
| 分诊记录完整率 | ≥ 98% |
| 二次分诊执行率 | 100% |
| 分诊准确率 | ≥ 95% |

## 8. 信息安全管理

- 患者急诊信息仅限诊疗相关人员查看
- 特殊事件和伤情信息不得擅自对外发布
- 分诊系统账号专人专用
- 纸质分诊记录按病历资料归档

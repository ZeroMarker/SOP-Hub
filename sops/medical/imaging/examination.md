## 1. 目的

规范医学影像检查预约、患者核对、检查准备、检查实施、报告发布和危急值通知流程，保障检查安全和报告质量。

## 2. 适用范围

适用于 X 线、CT、MRI、超声及其他医学影像检查的管理。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 影像检查申请 | 医师根据诊疗需要开具的影像检查医嘱或申请单 |
| 增强检查 | 使用对比剂提高影像诊断效果的检查 |
| 影像危急值 | 影像结果提示可能危及生命或需紧急处理的异常发现 |
| PACS | 医学影像存储与传输系统 |
| 检查禁忌证 | 不适合进行某项影像检查的情况 |

## 4. 职责分工

### 4.1 开单医师
- 正确开具检查申请并说明临床诊断
- 告知患者检查目的和注意事项
- 及时接收和处理危急值报告

### 4.2 登记预约人员
- 核对患者信息和检查项目
- 安排检查时间并告知准备要求
- 处理改约、取消和优先检查

### 4.3 技师
- 核对患者身份和检查部位
- 执行检查并控制图像质量
- 观察检查中患者状态

### 4.4 诊断医师
- 审阅影像资料并出具报告
- 对疑难病例进行讨论
- 发现危急值及时通知临床

## 5. 操作流程

### 5.1 预约登记流程

```
接收申请 → 信息核对 → 禁忌证筛查 → 预约排程
→ 告知准备事项 → 登记确认
```

**登记要求：**

- 核对姓名、年龄、检查项目、检查部位和临床诊断
- MRI 检查需询问金属植入物、起搏器等禁忌情况
- 增强检查需确认过敏史、肾功能和知情同意
- 急诊和危重患者按优先级安排

### 5.2 检查准备流程

```
患者到达 → 身份核对 → 准备情况确认 → 更衣/去除金属物
→ 检查说明 → 进入检查区
```

**准备要求：**

- 使用至少两项身份信息核对患者
- 确认检查部位和左右侧
- 需要空腹、憋尿或肠道准备的项目应再次确认
- 妊娠或疑似妊娠患者需按规定评估

### 5.3 检查实施流程

```
摆位 → 参数设置 → 图像采集 → 图像质控
→ 必要补扫 → 检查完成 → 患者离室
```

**实施要求：**

- 按检查规范选择体位、范围和参数
- 放射检查遵循正当化和最优化原则
- 增强检查中观察过敏反应和外渗情况
- 图像不合格时及时补扫

### 5.4 报告发布流程

```
图像上传 → 医师阅片 → 报告书写 → 审核签发
→ 临床查看 → 报告归档
```

**报告要求：**

- 描述客观、结论清晰
- 重要阳性发现需突出提示
- 疑难病例可进行双人阅片或会诊
- 报告修改需保留修改痕迹

### 5.5 危急值通知流程

```
危急发现 → 报告确认 → 电话通知临床 → 复述确认
→ 记录通知 → 临床处置反馈
```

**记录内容：**

- 患者信息、检查项目、危急发现
- 通知时间、接收人姓名和工号
- 复述确认情况
- 诊断医师签名

## 6. 特殊情况处理

### 6.1 对比剂过敏
- 立即停止注射
- 按过敏反应应急预案处理
- 通知医师并记录不良反应
- 后续检查标注过敏史

### 6.2 危重患者检查
- 由临床医护陪同
- 携带必要抢救设备和药品
- 检查期间持续观察生命体征

### 6.3 设备故障
- 暂停相关检查
- 通知设备工程师维修
- 重新安排患者检查或转至其他设备
- 记录故障时间和影响范围

|------|------|
| 患者身份核对率 | 100% |

| 危急值通知及时率 | 100% |
| 普通报告出具时间 | 按医院规定执行 |
| 急诊报告出具时间 | 优先完成 |
| 图像质量合格率 | ≥ 98% |

## 8. 信息安全管理

- 影像资料和报告仅授权人员可查看
- PACS 账号专人专用
- 患者影像拷贝需核验身份并登记
- 对外提供影像资料需遵守隐私保护规定

## 1. 目的

规范处方审核、调配、复核、发药和用药交代流程，保障患者用药安全、合理、准确，减少药品差错和用药风险。

## 2. 适用范围

适用于医院门诊、急诊、住院患者处方和医嘱的药品调配与发放管理。

## 3. 术语与定义

| 术语 | 定义 |
|------|------|
| 处方审核 | 药师对处方合法性、规范性和合理性进行审查的过程 |
| 四查十对 | 药品调配和发放中的标准核对要求 |
| 高警示药品 | 使用错误可能对患者造成严重伤害的药品 |
| 麻精药品 | 麻醉药品和精神药品，需按特殊管理规定执行 |
| 用药交代 | 药师向患者说明药品用法、注意事项和不良反应的过程 |

## 4. 职责分工

### 4.1 审方药师
- 审核处方合法性、规范性和合理性
- 发现不合理处方及时与医师沟通
- 记录处方干预情况

### 4.2 调配药师/药士
- 按处方准确调配药品
- 检查药品名称、规格、数量和效期
- 规范打印和粘贴用药标签

### 4.3 复核药师
- 对调配药品进行复核
- 确认患者信息、药品信息和用法用量一致
- 对高风险药品执行重点核对

### 4.4 发药药师
- 核对患者身份并发放药品
- 进行必要用药交代
- 解答患者用药咨询

## 5. 操作流程

### 5.1 处方审核流程

```
接收处方 → 合法性审核 → 规范性审核 → 适宜性审核
→ 审核通过/退回修改 → 审核记录
```

**审核内容：**

1. **合法性**：处方医师资质、处方日期、患者信息完整
2. **规范性**：药品名称、剂型、规格、数量、用法用量清晰
3. **适宜性**：适应证、剂量、疗程、配伍禁忌、相互作用、重复用药、过敏史
4. **特殊药品**：麻精药品、抗菌药物、贵重药品按权限和审批要求审核

### 5.2 药品调配流程

```
处方通过 → 打印配药单 → 药品定位 → 取药核对
→ 标签粘贴 → 调配完成 → 交复核
```

**调配要求：**

- 按先进先出、近效期先出原则取药
- 同名不同规格、外观相似药品重点核对
- 拆零药品需注明药名、规格、批号、效期和用法
- 冷链药品按温控要求调配和暂存

### 5.3 复核发药流程

```
复核药品 → 核对处方 → 呼叫患者 → 身份确认
→ 发放药品 → 用药交代 → 签字/系统确认
```

**四查十对：**

- 查处方，对科别、姓名、年龄
- 查药品，对药名、剂型、规格、数量
- 查配伍禁忌，对药品性状、用法用量
- 查用药合理性，对临床诊断

### 5.4 用药交代流程

**重点交代内容：**

- 药品服用时间、剂量、频次和疗程
- 饭前、饭后、睡前等特殊用法
- 外用、吸入、注射等特殊给药方式
- 常见不良反应和处理建议
- 储存要求和漏服处理

## 6. 特殊情况处理

### 6.1 不合理处方
- 暂停调配并联系开方医师
- 说明问题和修改建议
- 医师修改后重新审核
- 必要时记录处方干预

### 6.2 药品短缺
- 查询院内替代药品或库存
- 通知医师调整处方
- 告知患者取药安排
- 做好缺药登记和采购反馈

### 6.3 发药差错
- 立即停止发药或追回药品
- 评估患者是否已使用
- 报告药房负责人和医务部门
- 按不良事件流程记录、处理和复盘

### 6.4 麻精药品调配
- 核验专用处方和患者身份
- 双人复核、专册登记
- 空安瓿和废贴按规定回收

## 7. 服务质量要求

| 项目 | 标准 |
|------|------|
| 处方审核率 | 100% |
| 发药差错率 | 持续监测，重大差错为 0 |
| 高警示药品双人核对率 | 100% |
| 麻精药品账物相符率 | 100% |
| 用药咨询响应率 | 100% |
| 近效期药品管理合格率 | 100% |

## 8. 信息安全管理

- 患者处方信息不得向无关人员泄露
- 药房系统账号专人专用
- 麻精药品管理记录按规定保存
- 处方和发药记录按病历及药事管理要求归档
